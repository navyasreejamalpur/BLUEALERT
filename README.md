🌊 BlueAlert – Marine Plastic Intelligence

**AI-Assisted Marine Plastic Detection, Mapping, and Drift Simulation**

BlueAlert is a web-based application designed to support marine pollution monitoring by detecting floating plastic debris, mapping pollution hotspots, and visualizing potential debris movement using wind and ocean current data.

The project combines Artificial Intelligence (AI), Machine Learning (ML), and geospatial visualization to make marine plastic pollution monitoring more accessible and informative.

 🎯 Objectives

- Detect floating marine plastic debris from uploaded images using a machine learning model.
- Map detected debris locations and visualize pollution hotspots.
- Estimate debris distribution and display analysis statistics.
- Simulate potential debris drift using wind and ocean current parameters.
- Provide an interactive dashboard for marine pollution monitoring.

✨ Key Features

- AI-Based Detection: Analyze uploaded images to identify potential plastic debris.
- Interactive Mapping:Visualize debris locations and hotspots using interactive maps.
- Pollution Analysis: Display detection counts, estimated affected area, density, and confidence scores where supported by the analysis.
- Drift Simulation:Explore potential debris movement using wind and ocean current information.
- Geospatial Data:Export detected locations and related properties in GeoJSON format.
- Map Views:Switch between street maps and satellite imagery.

 🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
-Backend: Node.js and Express
- Machine Learning: Python and a trained object-detection model
- Mapping:Leaflet.js, OpenStreetMap, and satellite imagery
- Geospatial Data: GeoJSON
- Marine Data: Ocean current and wind information for drift simulation

⚙️ How It Works

1. Upload a satellite, drone, or other suitable marine image.
2. Provide the required geographic coordinates and image details.
3. The machine learning model analyzes the image for potential floating debris.
4. The application displays the detection results and available analysis statistics.
5. Detected locations can be visualized on an interactive map.
6. Users can explore a prototype drift simulation using wind and current parameters.
7. Export supported geographic results as a GeoJSON file.

 ⚠️ Limitations

BlueAlert is a prototype intended for demonstration and preliminary analysis. Detection accuracy depends on image quality and model performance. Estimated area, density, and confidence values depend on the implemented analysis methods. Drift results are simulations and should not be treated as validated forecasts or used for navigation.
